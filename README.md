## Face Enroll App 

This is written as a generic SwiftUI app for face enrollment. Used in places like conferences needing several signups

### Main Branch

- Base implementation

### Vision API branch

- Uses vision api to detect a face

## Features

- Captures image and username
- Posts to jsonplaceholder as an example
- Also saves data to SwiftData
- SwiftData is exposed in a view on the preview screen when the photo is clicked thrice


## Notes

- Can be used sign up users using image data and a username , this will work as is
